Six routes, one namespace, and the gates a request crosses in order

Every route lives under newspack-nodes/v1. WordPress checks a route's declared arguments before any permission callback runs, the fleet gate opens every permission callback, and only then does the route's own check decide. Read each column top to bottom.

Registration order is load-bearing

Bootstrap::register_rest_routes() runs on rest_api_init. /health/cache registers first, so REST init completes even when the runtime base directory is refused; the other five register only once that base is available and ensure_runtime_wired() has run. The slot-pool seams are wired in the same place, because reading them earlier would load the stream controller on admin and cron requests that never stream.

Two entry points outside the namespace

The settings page posts to WordPress's admin-post.php under newspack_nodes_reset_settings and newspack_nodes_flush_cache. Each is gated by its own nonce and by Capabilities::can( MANAGE ), the manage role, which the allowed_users config list narrows for every surface, and each answers with a redirect back to the settings page.
