make_node builds a node in a fixed order, and the order is what makes a dump replay

No-arg constructor, then name(), then arguments() with a flat token array, then sink(). Tokens ride verbatim; the one place they re-join into a line is Node::serialize_args(), so dump_config() emits make_node lines that rebuild the same graph.

1make_node <type> <name> <args…>The type resolves to the first concrete {prefix}{type}_Node across the registered namespaces (ADR-10). Positional args are filtered to scalars (array_filter( $ctor_args, '\is_scalar' )), re-indexed and cast to strings: an object cannot round-trip, so it is filtered with a rate-limited note and assigned later as a public property.
2is the name taken?
Identical class AND identical tokens: return the existing node. Replaying a dump or including a topology twice is idempotent.Anything else throws make_node conflict: '<name>' already declared as …
3new $fqcn()No arguments, no event-loop or filesystem work (ADR-5).
4name( $name )Registers the node. From here a throw leaves an orphan in the registry, which is why step 7 exists.
5arguments( $tokens )The base stores the token array and parses nothing. A node wanting declared positionals assigned to properties uses Schema_Reflection and calls parse_schema_args( $args ): it records the tokens for dump_config() and is the one source of defaults — a missing token takes the schema default, a missing required one throws Missing required argument: partition_dir. Derived state (Partition's partition_dir) computes after it returns.
6sink( $this )The interpreter that built it is its physical next hop, so every node sinks into _command_interpreter (ADR-7).
7 · unwind. A throw from steps 4–6 runs remove_node() on the half-built node, then rethrows: nothing is left half-built in the registry. Tachikoma CI:2701.

The round trip: dump_config() → serialize_args() → replay

Each token goes out through serialize_arg(), which single-quotes an empty token or one bearing whitespace, a quote, a backtick, a backslash, #, ; or <, and escapes \ and ', so the trip is lossless for any token.

< is on the list for a reason that is not tokenizing: interpolate() runs before tokenize(), so quoting is what keeps a stored <config:logs_dir> unexpanded on the next load.

A constructor sets $this->arguments, or the round trip silently produces a different node. State a VERB set needs an override that calls parent::dump_config() and appends its own config_line()s: Partition, Topic, Consumer, Remote_Source and Settings_Sync each do.

Skipping a positional: the empty-token placeholder

make_node Partition p /dir '' '' 7 sets num_segments while segment_size and min_segments keep their <config:segment_size> and <config:min_segments> defaults.

The placeholder works for int and float alone: a blank bool coerces to false and a blank string is the literal empty string. That asymmetry is why the topology console writes each declared default into an empty slot (applyDefaults() in src/topology-console/utils/tslArgs.js) and ends the line at the last argument the author set (trimTrailingEmpties()) before editorLines.js builds the make_node or set_arguments line. That copy of the rule, the runtime's parseSchemaArgs() and the PHP original are three separate copies; a change to one reaches neither of the others.

Three trait users hand-roll the check

Newspack_Log_Node, Graphite_Node and Table_Node use Schema_Reflection for the schema the palette and help read, never call parse_schema_args(), and read token 0 through Core::as_string() to throw a message of their own — Table requires a namespace argument. Nothing holds them to the schema's required flag. They are the standing exceptions; a new node conforms rather than joining them.

Amendment: a required positional yields to a point-of-use refusal

A dashboard whose subscription is chosen from a catalog must build its RemoteLink before anything names one. So a required positional is enforced at construction UNLESS the node refuses the same invariant at the point of use; where both exist the point-of-use refusal is the contract and the positional is optional. RemoteLink declares subscribe optional and _assertConfigured() throws on any verb that would open a stream. A verb handed the missing value configures the node with it — setSubscribe() and reconnect( subscribe ) assign through arguments, so the getter reports what is streaming rather than what the constructor was given, and past this class's own setter, so RemoteIpc's different positional (reader) is not overwritten. The accepted cost: a graph dumped while a node is still unconfigured emits a make_node line that refuses on replay, which beats a placeholder that replays cleanly into the wrong log.
