The operator's loop: edit, regenerate, restart, drive, watch

Every change to a node class or a topology line goes round once. The classmap is what make_node and the console palette read; the restart is what puts the new class in a running worker. Four messages tell you which step you skipped.

1

Edit

A node class under includes/, or a line in topologies/*.tsl: a new make_node, a new connect_node.

A second source, as §6 shows, is one class and two topology lines: its make_node and a connect_node pointing it at the summarizer.

2

Regenerate the classmap

composer dump-autoload -o

Whenever a node is added or renamed. make_node Foo resolves Newspack_AI_Newsletter\Foo_Node through this map, and the palette reads the same map for its tiles.

3

Activate, or restart

# first time: activate and spawn wp nodes activate example-ai-newsletter # after that: reload the topology wp nodes restart example-ai-newsletter

The shipped active set is empty, so nothing spawns until you say so. A running worker keeps the old class for the rest of its life; the restart is what replaces it.

4

Confirm the worker is up

wp nodes status # example-ai-newsletter.p0 live 3s ago 12s

One row per partition. live means a lock held under a fresh heartbeat.

5

Attach, and drive it

wp nodes cli example-ai-newsletter.p0 # then, at the worker's prompt: > request_node releases TICK > request_node digest FLUSH

Or open the Console tab of the Nodes admin page and click TICK and FLUSH in the Inspector: those buttons come straight from each node's requests.

6

Watch

The counts climb along releases, summarizer and digest while the edges animate, and every FLUSH lands a new digest.md.N segment.

None of this observability is yours to build: every node speaks fill() and announces itself through node_schema(), so the console renders and drives a graph it has never seen.

unknown class: Releases_Source

The plugin is not active, or the classmap is stale. Activation first: register_plugin() runs on plugins_loaded, which fires only for activated plugins, so an inactive plugin registers no namespace. Regenerate second.

message not addressed

On stderr, once. An emitted item reached _router with an empty TO: nothing is wired downstream yet. connect_node sets the target that fills it.

storage path … is outside the runtime base directory

Every node that writes segments asserts its directory lies inside the base directory. Spell it with <config:logs_dir>, which the Shell resolves to {base_directory}/logs before make_node sees the line; wp nodes doctor prints the resolved base.

WARNING: no secure level declared

About once a minute on the Router tick, for a worker still at level 0. The walkthrough leaves secure out so you can keep typing make_node in the attached REPL; a production file closes with it, and level 1 refuses make_node, move_node and remove_node. request_node runs at every level.
