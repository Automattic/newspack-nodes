Which cache backend each process needs, and why

APCu is one PHP pool's own shared-memory segment; Memcached is reachable from every process configured for it. Either alone brings the runtime up. With neither, command verification fails closed, because a single-use nonce cannot be claimed anywhere.

What wp nodes doctor reports

The cache-backend row asks the WEB runtime over the loopback, because a CLI process sees a different posture. Command_Auth: no APCu and no memcache; refusing command (single-use unverifiable) in the log is the same fact seen from a verifier: every wire command is refused until one backend answers.
