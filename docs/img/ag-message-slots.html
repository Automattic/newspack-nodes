A message is one positional array, and the wire is the same array as JSON

Seven slots cross every boundary. An eighth, LOCAL, exists only inside the process that minted the message: packed() slices it off, which is what makes it a provenance taint rather than a field.

The array, in index order — Message::TYPE … Message::VALUE, then the in-process LOCAL
0TYPEa bitmask of the eleven flags below; mint default TM_UNTYPED
1TIMESTAMPunix SECONDS as a float, microsecond resolution; PHP stamps the cached per-tick Core::$now, JS Date.now() / 1000
2FROMthe trail behind: one name per source or boundary, / separated, at most 1024 bytes
3TOthe path ahead; the Router peels one head per hop; a reply carries the request's FROM
4IDa producer's identifier; a Consumer writes its {seg}:{off}:{len} crumb here, never in KEY
5KEYthe routing / partition / grouping key a Topic hashes
6VALUEthe data: a line, an array, a live command struct { name, arguments, auth }
packed() stops here
7LOCALset by a Shell minting in-process; the client-tier authorize gate tests isset(). Never on the wire, never in IPC.

Message::packed() → one JSON list

json_encode under JSON_UNESCAPED_SLASHES | JSON_INVALID_UTF8_SUBSTITUTE, falling back to wp_json_encode. A bad UTF-8 byte is substituted, so one latin1 column cannot void a record. It never returns '': a residual encode failure logs to stderr and substitutes a self-describing TM_ERROR frame.

packed_size() measures that JSON alone; a writer sizing a record adds one for Partition's newline.

PHP unpacked() — strict

Accepts count() === 7 && array_is_list() and nothing else; anything else throws InvalidArgumentException.

Off-disk readers catch it: Durable_Reader::forward_line quarantines the line to :deadletter and advances; Partition_Node::last_frame_of logs it and hands back null, so the reader boots with no durable cursor.

JS unpack() — lenient

Accepts Array.isArray && length >= 7, truncating to the canonical seven. Anything else, a JSON parse error included, yields a fresh newMessage() — never a throw.

It never returns a short array, so a caller indexes VALUE unconditionally, and a peer's trailing eighth field claiming LOCAL provenance is truncated away.

TYPE: eleven one-bit flags, four planes. Compose with |, test with &, never ===

= 1TM_BYTESTREAM — a raw line
= 16TM_STRUCT — an array VALUE
= 8TM_COMMAND — build and administer: make_node, connect_node, config verbs, topology load
= 128TM_REQUEST — drive or query a LIVE graph: GET_HEALTH, Table GET
= 256TM_RESPONSE — an answer; a verb reply is TM_COMMAND | TM_RESPONSE
= 512TM_NOREPLY — fire-and-forget; a Shell with want_reply(false) ORs it on and the interpreter replies only with an error to stderr
= 64TM_INFO — a flat KEY VALUE string from set_state / notify
= 2TM_EOF — the cli's drain marker; bounced TO=FROM
= 4TM_PING — VALUE is the send time; the Dumper prints the round trip
= 32TM_ERROR — replaces TM_RESPONSE on a throw; NOT_AVAILABLE rides here
= 1024TM_UNTYPED — the mint default; matches no gate, so one reaching a sink is a bug the drop audit names
Planes: data (blue), control (amber), lifecycle (green), error (red). TM_COMMAND | TM_RESPONSE is 264, and 264 === TM_RESPONSE is false: an equality test misses every combination.

Two control planes, two destinations

A command runs once at build time and is dispatched by a Command_Interpreter_Node from the verb table node_schema()['commands'] declares. A request fires against a running graph and is handled in the addressed node's own fill() — branch on $type & TM_REQUEST, reply TM_STRUCT | TM_RESPONSE to TO = FROM — declared under node_schema()['requests']. A runtime trigger is never a cmd_* verb.

One shape, everywhere

PHP, JS (src/runtime/message.js exports the same indices and flags), memory and wire hold the same list. There is no { type, ts, from, to, id, key, value } object anywhere; $message['type'] silently appends an eighth element that packed() drops.
