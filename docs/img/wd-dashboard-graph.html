Three independent reply paths

A counts reply reaches source-counts:view and nothing else. Add a fourth slice and it is still one POST per tick, and still nothing crosses. Every edge is a place to drop a Tee, watch in the debug overlay, or reuse.

The god node this avoids

One insights verb computing { sources, top, accumulated }, one view node, one component. It sits at counter 0 / 0 B in the topology console: nothing to Tee, nothing for the overlay to show, nothing reusable. Decompose both sides: three verbs, three Fetchers, three receivers, three views, three widgets.
