One registry on window, one TabHost, two hosts

Every tab-bearing bundle registers a descriptor at import time; each host reads its own tabs plus the both ones and mounts only the active one. The registry lives on window because each bundle is its own IIFE: a module-local map would give the station one empty registry per bundle.

how a lazy station tab arrives
newspack_nodes/station_tab_bundlesPHP filter; each entry { handle, dir, url, localize?, lazy? }. enqueue_station_tab_bundles() runs on the station page alone and skips an entry missing handle, dir or url.
window.NewspackNodesLazyTabsfor each lazy: true entry, lazy_tab_script() writes a load recipe: versioned index.js, its style, its localize data. No built index.js, no recipe.
lazyTabs.js · LAZY_TABSfour { meta, handle } pairs by hand: Console, Vault, Sessions, Aggregator. Each registers a placeholder spreading its tabMeta.js, so label, order, slug and fullBleed resolve before any bundle loads.
first activationMounting IS activation: the placeholder renders Loading… and calls loadTabBundle( handle ), which injects the script. The bundle's own tabs.js spreads the same tabMeta with its component, and its registerTab shadows the placeholder by id.

What TabHost does for every tab

1
Mounts only the active tab, keyed on its id, so each tab's build-before-render runs fresh on every switch; host is applied after tabProps spreads, so a caller cannot hand a tab the wrong surface.
2
Hides the bar at one tab; adds .is-full-bleed to the pane for a fullBleed tab, opting it out of the default vertical scroll.
3
WAI-ARIA tabs: role="tablist" over role="tab" buttons and one role="tabpanel", a roving tabIndex, arrow keys wrapping at both ends, Home and End; every other key falls through.
4
Lands on whichever tab sorts first at first render, resolved once in a lazy state initializer. Overview holds that slot only because Admin registers enqueue_event_dashboards_assets() ahead of enqueue_station_assets() on the same hook.

syncUrl, and the one thing a consumer cannot do

The initial tab comes from ?tab=<slug>; the resolved tab is mirrored back through replaceState; a tab's declared param survives only while it is showing. The first click retires the initial slug for the page's life; until then a slug no tab holds yet is retried on every registry version bump, which is what lets a slow lazy bundle still be reached by link.
lazy is substrate-internal. LAZY_TABS has no filter, and loadTabBundle() sits in src/station/, which no alias reaches. Mark a consumer bundle lazy and PHP writes its recipe correctly, nothing registers a placeholder, the tab never joins the bar, and nothing logs a word. Ship an eager bundle, as event-logger-nodes' Request tab does.
