Five files, one graph: three connectors, two durable logs, one observer

The toy's boxes and arrows with real ends and a durable ingest layer in front. Each stage ships as its own .tsl; the aggregator includes the four. Activate it or a stage alone, never both.

connect_node a Consumer tailing a Partition under its own offsetlog a durable Partition on disk calls the LLM, blocking, in the worker (the gate only when inconclusive) stock node

A secure inside an included file is skipped

Shell_Node::declares_secure_level() drops it, so only the topology being loaded decides the process level. Without that skip the ingest stage's secure would refuse every make_node in the three stages behind it. secure climbs the ratchet one level; at level 1 make_node is refused, so the built graph can no longer be rebuilt from the wire.

The gate observes and moves nothing

gate:consumer tails the same ingest.p0 under its own offsets/gate.p0, so it never advances the summarizer's cursor. gate runs Publisher_Matcher on each item to ask whether it concerns a Newspack client: the URL domain, then an exact name or alias, then the domain stem, and only when all three are inconclusive an LLM entity extraction, none when no token resolves. The decision record lands in gate-decisions.jsonl; nothing is filtered out of the digest.
