The example pipeline: nine nodes, one durable log, and three requests you type

Beside one var and three cmd lines (two void_warranty, one add_snapshot_node), example-ai-newsletter.tsl is make_node and connect_node statements. The sources emit nothing on their own: each TICK pushes canned items down the whole chain, and FLUSH writes what the consumer has delivered so far.

releasesReleases_Source_Demo: 2 canned items on TICK
communityCommunity_Source_Demo: 3 canned items on TICK
summarizerSummarizer_Demo: adds a one-line summary
scorerScorer_Demo: adds a notional score
scored:partitiondurable; void_warranty lifts the 4 KB cap
scored:consumerdurable cursor; snapshots digest into its offsetlog
digestDigest_Builder_Demo: accumulates; renders on FLUSH
digest:teeTee, one target
digest:logLog <logs_dir>/digest.md 1 2 7 0 0 0
/example-ai-newsletter.p0> request_node releases TICK
{ "emitted": 2 }
TICK and FLUSH are TM_REQUESTs, sent with request_node, not admin commands. The reply rides the FROM breadcrumb back to the REPL while the items flow downstream, so watch the console counters climb card by card.
/example-ai-newsletter.p0> request_node community TICK
{ "emitted": 3 }
Five items now sit in scored:partition. The consumer paces the durable log, so give the ticks a beat before flushing.
/example-ai-newsletter.p0> request_node digest FLUSH
{ "flushed": 5 }
flushed counts what the consumer had delivered by the time you typed it. The draft opens # Newsletter draft and lists one bullet per summary.

Where the draft lands

{base_directory}/logs/digest.md.0, where base_directory defaults to /tmp/newspack-nodes and wp nodes doctor names the resolved path. A Log writes segments {file}.0, {file}.1, … and never a bare {file}. This Log's segment_size is 1 byte, so it rotates on every write: a second FLUSH lands in digest.md.1, and the count rule keeps seven.

Nothing is created by hand

Every path hangs off the runtime's base directory, and each node creates its directory as it first needs it. The log paths say example-scored rather than scored so the demo's data stays apart from a real plugin's scored log in the same substrate dir.
