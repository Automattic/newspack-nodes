L2 Merges over the base schema, so the verbs every node answers stay declared.
L3 category groups the node in the console palette.
L5 arguments are positional: the words after the name on a make_node line.
L6 A request is a runtime trigger. fill() handles it on the TM_REQUEST flag; request_node fires it; reply_shape documents the answer.
commands A configuration verb, run when the graph is built. A node declaring one gets a sibling interpreter named <node>:config, reached with command_node.

fill( $message ), the one entry point

Handle the flags you answer, transform what you forward. A node that generates a message calls parent::fill(), which stamps the destination from its target and forwards to the sink.

Never $this->fill()

Calling the node's own fill() to send a message re-enters the handler and recurses. parent::fill() is the way out.

Each node tests alone

Build a message, call fill(), assert on what lands in a Capture_Sink_Node. No worker, no fleet.
