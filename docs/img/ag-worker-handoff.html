A worker's last act is to start its successor, and release comes before the respawn

Five hops from the end of drain() to the successor's acquire(). The finally block runs the handoff, the teardown, the release and the spawn in that order, and the order is the mechanism: reversed, the successor hits a held lock and the slot idles until a peer's rescue.

Spawner

A predecessor's self_respawn(), a peer's _fleet scan, the cron pass, an activate, or a wake.

Spawn endpoint

POST /newspack-nodes/v1/workers/spawn, Spawn_Controller.

Worker_Base

execute( $topology, $spawn_url, $token ) inside that same request.

Lock dir

{base}/locks/{type}.p{N}.lock.d/ — the slot.

Successor

The next process in this slot.

1finally, and a register_shutdown_function for an exit() that skips it — both check shutdown_handled, first one wins. shutdown_handoff(): sweep every named Shutdown_Sweeper synchronously, then checkpoint each durable reader — the fair-shot rule for timeout and memory, a graceful frame for everything else, nothing at all on a fatal.
2Core::cleanup_all_nodes() tears the Partitions down so their write locks go before the next spawn.
3release(): Partition_Node::flush_pending_wakes() FIRST, while the lock still reads held, then drop the lock. Spawn_Coordinator::wake_on_demand() judges a reader absent by its lock dir, so a wake flushed after the release, for a partition this worker tails (its own IPC input included), would find the slot free and spawn a duplicate.
4should_self_respawn() refuses two categories, idle and stop. Otherwise self_respawn() mints a fresh token through Worker_Base::$token_provider, because the boot token is ~595 s old and outside the 10-second windows; left unwired, every respawn is refused and succession degrades silently to the peer scan and cron. Spawn_Controller runs its checks and then the successor, inline in the request that POST opened.
5The successor reaches acquire() before this process has fully exited. No retry loop, no waiting. Reversing steps 3 and 4 would have the successor hit the still-held lock, skip, and idle the slot until a peer's rescue.
