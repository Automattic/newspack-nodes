Edit mode is the live console over a draft registry: load in two steps, edit by the same commands, write one ordered file

What changes between view and edit is which interpreter receives a line, and that is a cwd. A DraftInterpreterNode keeps its nodes in a NodeRegistry of its own, so a draft firehose neither collides with nor sees the live one; the clock, the rate-limited stderr and the rest of Core stay shared.

Load — only the server can resolve an include, so the borrowed half comes first
1DraftInterpreterNode.includesOf( tsl )A static read of which topologies the file includes, without running it.
2topologies expandComposes the include set into { nodes, edges, tree, hulls }. Cached at module scope under the joined include list, order included; topologies get primes it, and saving or deleting ANY topology clears it all. A refusal — a cycle, a conflicting make_node, an unknown name — is an error with the expansion empty, never a valid empty graph.
3load( tsl, baseline, resolvedConfigEdges )Seeds the borrowed half from the baseline — each node carrying origin and via, drawn locked, its form read-only — then runs the file's own statements. Every seeded node is a StubNode, whatever its class. Called with no baseline, it treats the file as including nothing, silently.
4A class outside the bundle's includeNodes becomes a StubNoderesolveClass() knows only the classes the browser bundle registers, so Partition, Topic, Consumer, Job_Worker and every other server-side class stub. A stub keeps the declared class, which dump_config and dump_metadata emit in place of Stub, the tokens verbatim and the catalog's fans_out flag; its fill() counts and drops.
Edit — DraftContext is the only way in; graph is a read, never mutated
5run( line )The command face, identical to live mode. Re-declaring a borrowed name CLAIMS it: the borrowed node goes, the replacement inherits its outgoing edges, and a failed build restores both. move_node rewrites every reference: seeded edges, other nodes' target, and node_name-typed verb arguments.
6Whole-map edits one line cannot spellreplaceVerbs (a command_node only appends), replaceFrontmatter, clearSecure (insecure declares a third state), reseed( from, to ), assertResolved() for a <ns:key> target, revertIncludes( lastGood ) after an expand error, setCatalog.
7draftToGraph() after every changeWalks the draft registry into { nodes, edges, includes, frontmatter, secureLevel, configOverrides, resolvedConfigEdges }. x and y are zero and _repl is never synthesized; a set_*target on a borrowed node becomes a configOverrides entry.
8augmentWithVirtualEdges()A node reached only through a node_name verb argument — set_errors_target errors:partition — gets a dimmed virtual: true edge, so autoLayout places it downstream; click-to-delete is refused, since a disconnect_node would not remove the verb line.

Dirty is a comparison, and save is the one write

Dirty means the graph's serialization differs from a baseline the document carries. load() records what it loaded; an upload records null and is dirty from its first render. markSaved() stamps what was SENT, because a save takes seconds while the canvas stays live. topologies save writes the user .tsl and restarts every fleet running it, so it goes exactly once; the console then re-baselines on what was WRITTEN and offers to activate a new topology, which a save leaves inactive.

Four verbs belong to the FILE

var, include, remove_include and secure touch no node table, and here secure edits a line in both directions where live it is the one-way ratchet. The Palette offers every catalog topology as a tile and disables three: the one being edited, one already included, and one whose include closure reaches it — a client mirror of Topology_Analyzer's cycle guard that has to move with it.

Arguments are SPANS, and quoting changes meaning

serializeDraftArg() emits a span that already tokenizes to itself verbatim, because double quotes interpolate <name> where single quotes and backticks defer. It quotes only an unbalanced quote and a bare # or ;. utils/tslArgs.js writes each blank positional's schema default and trims only trailing empties: PHP counts an empty string or bool token as supplied, and dropping an interior blank would shift every later argument.
