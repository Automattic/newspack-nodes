The cross-tenant edge

A reply accepted from one publication's egress is delivered by name — and another publication's offsetlog is a name.

Its last frame seeds that publication's durable consumer cursor (Remote_Source::restore_position()). There are 24 of them.

Isolation between customers is naming discipline, not a boundary the runtime enforces.

Nothing in the registry records which spoke a node belongs to. firehose:clevescene:firehose.p0:offsetlog is reachable from anywhere in the graph that can put a name in TO.
