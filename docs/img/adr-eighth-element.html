Seven slots on the wire, one taint that never reaches it, and a string key that vanishes

The wire shape IS the memory shape: packed() is JSON of the array, sliced to LAST_VALUE_INDEX + 1, and unpacked() accepts a seven-element list and nothing else. Whatever a caller appends past index 6 is dropped before the wire, which is a feature for one field and a silent-corruption footgun for a typo.

Rejected: an associative array or a value object

Hash lookups ($message['type']) are measurably slower than indexed access in the drain loop, and an object form reintroduces a translation layer at every PHP / JS / wire / memory boundary. If you see an object form it is a bug to delete.

The divergence budget against Tachikoma

KEY not STREAM, VALUE not PAYLOAD, TIMESTAMP at index 1. TM_BYTESTREAM (string VALUE) and TM_STRUCT (array VALUE) are mutually exclusive; array-VALUE consumers gate on TM_STRUCT. Anything further must be justified separately.

Revisit only if both hold

Profiling shows associative arrays are no longer slower in the drain hot path, AND a typed value object can eliminate the string-key footgun without a wire/memory translation layer.
