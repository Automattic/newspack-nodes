One tick moves every message: the drain loop wakes, the Router ticks, and each hop is one fill()

Three tiers, one process. The Event_Framework decides when to wake; the Router decides where a message goes and carries the per-second chores; the node graph is nothing but fill() calls handing an array along.

No try guards any of it in PHP. A hitchhiker's fire() that throws takes the rest of the walk and all three chores with it, and the throw ends the worker. Only Worker_Should_Stop may escape a hitchhiking fire().
