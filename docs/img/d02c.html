A reply needs no bookkeeping: TO is the request's FROM

One typed line crosses two processes and a pair of logs on disk, and comes back. Nothing holds a table of outstanding requests, matches an id, or resolves a promise. The address the caller mints is the correlation.

hops 1 to 4, the command going out
hops 5 to 7, the reply coming back, each router peeling one segment off TO
Console process · wp nodes cli, pid 4242
The two logs on disk
Worker process · job-worker.p0

1 The shell mints the command

FROM = _output/4242
TO   = job-worker.p0

You type a line. _output is the reply renderer's name and 4242 is the process id, so FROM is the address an answer has to reach.

2 The console's router forwards

It splits TO at the first slash, finds job-worker.p0 in its own table of nodes, and hands that node the remainder, which is empty.

3 The input log

That node appends the command to the worker's input log. The two processes share no memory: the file is the channel.

4 The worker's reader stamps FROM

FROM = _repl/_output/4242
TO   = empty

Crossing into the worker puts one more name in front of FROM: _repl, the output log's name, the way back out.

5 The interpreter answers

TO   = _repl/_output/4242
FROM = _command_interpreter

TO is empty, so the command is for this process. The interpreter runs the verb and copies the request's FROM into the reply's TO, along with its id and key.

6 The output log

TO   = _output/4242

The worker's router peels _repl, and the reply lands on disk addressed to what is left.

7 The renderer prints, and only for its own console

TO   = 4242

The console's router peels one more segment and hands its renderer a reply addressed to 4242. The renderer prints it only when that is its own process id, so several consoles share one output log without seeing each other's answers.

FROM is bounded at 1,024 bytes

A loop would grow the trail without end, so a node refuses to stamp past Node::MAX_FROM_SIZE, and the router drops a message that arrives over it. A message off the wire is stamped by another process, out of reach of the first check.
