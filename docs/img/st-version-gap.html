The substrate ships first, so a host runs new substrate against an old consumer

A consumer pins a substrate tag, so the tag has to exist before the consumer can build. The window is guaranteed, not hypothetical, and two mechanisms cover it from opposite ends: the consumer declares a floor, and the substrate degrades a new parameter until every floor has passed it.

One parameter's life across the window: Partition_Node::locate_by( $extract, $wanted )

From the consumer's end: the floor

Bootstrap::version_at_least( $min, $dependent ) returns false and posts an admin notice naming the plugin, the version it needs and the version it found, so a consumer built against a newer substrate stays dormant instead of fataling mid-request.

Guard the call with method_exists()

A substrate predating the method carries no such method, so the call meant to prevent a fatal becomes one. Event-logger-nodes, intelligence and cache-cozy each test for it first.

scripts/check-substrate-floor.sh, authored here and vendored into every consumer though only event-logger-nodes' pre-push runs it, proves the floor covers every substrate API the plugin calls: PHPStan resolves each call to its declaring class, then the script searches the substrate's tags for the first release that answers it, walking traits and the extends chain the way PHP would.

Sound, not complete

A call counts only where PHPStan resolves the callee to ONE definite declaring class. A dynamically-named method, or a callee typed as a union or mixed, goes uncounted, so the floor the script reports is a lower bound, not a guarantee for code shaped that way.

From the substrate's end: a new parameter degrades

Adding a required parameter to a public method closes the window with a fatal instead. A default whose behaviour is safe and useless — [], which reads nothing — is what lets a stale consumer degrade until it catches up.

Inside the window

The bridge stands. A consumer compiled against the one-argument form comes back empty rather than raising ArgumentCountError through a seam that catches nothing, which would be a 500 on every dashboard request.

Past the window

The bridge comes out. With each caller's floor past the release that added the parameter, an optional parameter left standing only hides a forgotten argument.
